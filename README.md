# Octagon Web

Página pública del gestor de bases Octagon. El explorador de ejemplo usa datos ficticios y no se conecta a ningún motor. El portal de beta es externo a esta página. Los códigos de invitación, las claves de firma, los perfiles y los instaladores privados no se guardan aquí.

`npm ci --ignore-scripts && npm run build` genera los archivos estáticos. GitHub Actions publica `dist/` en GitHub Pages desde `main`. Las rutas de assets son relativas para el prefijo `/octagon-web/`.

El emblema de Octagon se usa como marca del producto. Las fuentes Manrope y DM Mono se distribuyen mediante sus paquetes Fontsource bajo sus respectivas licencias.
